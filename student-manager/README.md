# Student Manager

A command-line student management application developed in Python as part of my programming studies.

## Features

* Register students
* Display student information
* Search for students
* Manage student data

## Concepts Practiced

* Lists
* Dictionaries
* `while` loops
* `for` loops
* Conditional statements
* User input
* Dictionary methods
* List manipulation

## How to Run

```bash
python main.py
```
