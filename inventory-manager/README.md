# Inventory Manager

A command-line inventory management application developed in Python as part of my programming studies.

## Features

* Add products
* Display registered products
* Search for products
* Update product information
* Remove products
* Manage stock quantities

## Concepts Practiced

* Lists
* Dictionaries
* `while` loops
* `for` loops
* Conditional statements
* User input
* Dictionary methods
* List methods
* Searching and updating data

## How to Run

```bash
python main.py
```
