# Task List

A simple command-line task management application developed in Python as part of my programming studies.

## Features

* Add tasks
* Display registered tasks
* Remove tasks
* Sort tasks
* Exit the application

## Concepts Practiced

* Lists
* `while` loops
* `for` loops
* Conditional statements
* User input
* `enumerate()`
* `append()`
* `pop()`
* `sort()`

## How to Run

```bash
python main.py
```
